# FC 27 Clubs Pro Discord Bot

A personal project focused on building a Discord bot for
EA SPORTS FC 27 Clubs Pro statistics and club management.

## Project Status

In development.

## Current Features

- Discord bot integration
- Secure environment variable configuration
- Discord slash commands
- `/ping` health check command

- Match history

- Performance reports
- FC 27 Clubs Pro API integration

- Git
- Discord API
